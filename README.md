## 專題題目
GPU 預約系統

## 專題內容
### 簡述
本專題主要開發一套 GPU 預約管理系統，讓使用者可以透過網頁預約 GPU 資源，方便進行人工智慧模型訓練、深度學習及其他需要 GPU 運算的工作。
系統提供使用者查看 GPU 申請狀態、選擇預約日期與時間，以及取消預約等功能，避免多人同時使用相同 GPU 而造成資源衝突。
管理者則可以查看所有預約紀錄、管理使用者及 GPU 資源，提高設備的使用效率。

### 主要功能
使用者登入：提供帳號登入與身分驗證。
GPU 狀態查詢：查看 GPU 是否空閒或已被預約。
GPU 預約功能：選擇 GPU、使用日期及時段進行預約。
預約紀錄管理：查看、修改或取消自己的預約。
管理員功能：管理 GPU 設備、使用者及預約紀錄。

### 預期成果
希望透過本系統，讓使用者能更方便地預約 GPU，減少資源使用衝突及人工管理的時間，提升 GPU 設備的使用效率。
